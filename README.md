# Loon Plugin Snapshot

2026-11-01 本地快照。保留第三方作者与出处；第三方内容的权利和使用限制仍适用。

插件与已获取的 JavaScript/JQ 已保存并改写为本仓库链接，不自动同步上游。未执行远程脚本。

## 限制

仍有 3 个脚本缺失，原地址保留；具体条目见 snapshot-report.json。脚本中的外部 API、图标、配置和动态依赖仍可能依赖上游，因此不能保证完全离线或永久可用。

在 Loon 中导入下列 raw 插件地址；请按需选择，避免同时启用冲突插件。
